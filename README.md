# Portfólio de Daivisson Oliveira

Este projeto é um portfólio pessoal desenvolvido para apresentar minha trajetória como estudante e entusiasta de tecnologia, com foco em desenvolvimento web, organização, lógica de programação e cibersegurança.

A página reúne informações sobre minha formação, tecnologias que estudo, projetos pessoais, certificações e formas de contato, com uma interface visual moderna e responsiva inspirada em temas digitais e futuristas.

## Visão geral

- Apresentação pessoal e profissional
- Seção de "Sobre mim" com trajetória e objetivos
- Área de tecnologias e ferramentas utilizadas
- Destaque para projetos em desenvolvimento
- Catálogo de certificados e formações
- Botões de contato para redes e e-mail
- Design responsivo para desktop e mobile

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Estrutura estática de portfólio
- Imagens e assets locais para apresentação visual

## Estrutura do projeto

```text
portfolio/
├── index.html
├── assets/
│   └── imagens e recursos visuais
├── certificados/
│   └── arquivos PDF de cursos/certificações
├── README.md
└── imagens do projeto na raiz
```

## Como visualizar o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador, ou iniciar um servidor local para uma melhor experiência:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
